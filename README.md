# Learning Design Patterns

This repository contains my notes and code examples on the `Discover the modern implementation of design patterns with С++` Udemy course, which I took during the spring and summer of 2026.

## Course Summary

During the course I not only learnt DP-s, but I also discovered:

- build systems more and how to build with g++
- what is a Pseudo code and an UML diagram
- C++ OOP principles and syntax (I still feel my shortcomings on this topic)
  - classes, objects, inheritance, polymorphism, encapsulation
  - technical definitions, like constructor, member function, etc.
  - what is a virtual function or an abstract class
  - when to use const
  - operator overloading
  - initialization order of class members
- how to configure Zed with `Task`-s and shortcuts

At last, I created a `Summary` folder, where I summarize the key concepts and patterns learned throughout the course. Each design pattern is explained with its purpose, structure, and real-world examples. This serves as a quick cheat-sheet for reference, when needed.
